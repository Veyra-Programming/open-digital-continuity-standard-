## 🔒 Reporting a Vulnerability

The ODCS community takes security and cryptographic integrity seriously, especially regarding offline data persistence, local key derivation, and synchronization replay attacks.

If you believe you have discovered a vulnerability in the ODCS specification or reference client implementations:

1. **Do NOT publicly disclose the issue** in GitHub issues or public forums.
2. Email the Security Coordination Team at `security@odcs.in`.
3. Include:
   - Detailed description of the vulnerability.
   - Attack vector and affected layer (Layer 1 through Layer 4).
   - Minimal proof-of-concept (PoC) code or scenario.
   - Potential impact on offline nodes and upstream coordinators.

### Vulnerability Response SLA
* **Initial Acknowledgment:** Within 48 hours.
* **Triage & Assessment:** Within 5 business days.
* **Advisory & Coordinated Disclosure:** Within 30 days of confirmed patch availability.
