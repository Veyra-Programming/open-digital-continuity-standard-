ODCS-LEGAL-003 • CRITICAL SYSTEMS

Security Architecture & Vulnerability Disclosure

SAFE HARBOR ACTIVE

Digital continuity is mission-critical systems infrastructure. ODCS is designed to protect patient vitals during disaster blackouts, banking transactions across partition splits, and edge telemetry in remote field installations. Cryptographic verification and secure memory management are core design tenets.

1. Core Security Invariants

  • Durability Invariant (L1): Mutations committed to the local Write-Ahead Log cannot be overwritten or silently erased by network disconnects or process termination.
  • Cryptographic Immutability: All durable records instantiated in Haven Language compute deterministic SHA-256 hashes and reject post-initialization field modification at the VM bytecode level.
  • Convergence Invariant (L2): CRDT mathematical proofs ensure multi-master replication does not suffer race-condition state corruption.
  • Zero Intent Loss Invariant (L4): State transitions generate cryptographic receipts assuring tamper evidence.

2. Scope of the Vulnerability Program

The ODCS Security Team welcomes responsible vulnerability reports across the following systems surfaces:

  • Haven Language C VM, tokenizer, and bytecode compiler (PCbuild/amd64/haven.exe).
  • Standard Cryptographic Libraries (RFC 8785 Canonical JSON, SHA-256, Merkle DAG generation).
  • CRDT State Stores (VectorClock, PNCounter, AWORSet, LWWRegister).
  • Cloudflare Edge Continuity Worker (_worker.js).

3. Coordinated Disclosure SLA

  • Initial Response: Within 24 hours.
  • Severity Triage: Within 72 hours.
  • Remediation Target: Critical fixes deployed within 14 days before public advisory release.

4. Safe Harbor Guarantee

Security researchers acting in accordance with coordinated disclosure guidelines will not face legal action, dmca claims, or referrals to law enforcement. We value the global security community's support in hardening digital continuity infrastructure.

Security Reporting: Please report findings directly to security@odcs.in or Lead Architect Anirudha Puthraya.
